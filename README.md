## 📸 About the Project
A handy browser-based tool that instantly converts temperature values between the three major units — Celsius, Fahrenheit, and Kelvin. The user selects the input and output units from dropdowns and gets an instant result.

## ✨ Features
- 🌡️ Converts between **Celsius, Fahrenheit, and Kelvin**
- 🔽 Dropdown menus to select source and target units
- ⚡ Instant conversion on input
- 📱 Mobile-friendly with responsive viewport

## 🛠️ Technologies Used
| Technology | Purpose |
|---|---|
| HTML5 | Page structure, input and dropdown elements |
| CSS3 | Styling and layout |
| JavaScript (ES6) | Conversion logic and DOM manipulation |

## 🧮 Conversion Formulas Used

| From | To | Formula |
|---|---|---|
| Celsius | Fahrenheit | `(C × 9/5) + 32` |
| Celsius | Kelvin | `C + 273.15` |
| Fahrenheit | Celsius | `(F − 32) × 5/9` |
| Fahrenheit | Kelvin | `(F − 32) × 5/9 + 273.15` |
| Kelvin | Celsius | `K − 273.15` |
| Kelvin | Fahrenheit | `(K − 273.15) × 9/5 + 32` |
